# 卡券货源导航站

> **网站定位：仅收录第三方发卡站点，只做「站点导航 + 一键比价」工具。**
> 本站不卖货、无下单、无支付、不接触卡密交易，所有交易均跳转第三方网站。

## 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Node.js + Express | 原生 `node:sqlite` 存储，无任何原生编译依赖 |
| 爬虫 | 原生 fetch + cheerio | 只抓第三方前台公开搜索页，3 套解析规则 |
| 前端 | Vue 3（CDN 引入） | 单页应用，浅蓝简约卡片风，移动端优先，**无需构建** |
| 后台 | Vue 3 管理页 | `/admin.html`，Token 登录 |

## 目录结构

```
kaquan-nav/

│   └── style.css     # 全站样式

```

## 快速部署

**环境要求：Node.js ≥ 22.5（使用内置 sqlite 模块）**

```bash
# 1. 安装依赖
npm install

# 2. 启动
npm start
# 默认 http://localhost:3000

# 3. 生产环境（可选环境变量）
PORT=80 ADMIN_USER=admin ADMIN_PASSWORD=你的强密码 node src/server.js

# 4. 常驻运行（Linux，任选其一）
npx pm2 start src/server.js --name kaquan-nav
# 或
nohup node src/server.js > app.log 2>&1 &
```

Windows 直接 `npm start` 即可。

- 前台地址：`http://你的域名:端口/`
- 后台地址：`http://你的域名:端口/admin.html`
- 后台默认账号：`admin / admin123`（**务必用 ADMIN_PASSWORD 环境变量修改**）

Nginx 反代示例：

```nginx
server {
    listen 80;
    server_name yourdomain.com;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 后台功能说明

| 模块 | 功能 |
|---|---|
| 站点管理 | 新增/编辑/删除；设置发卡系统；开关【参与比价抓取】；置顶、赞助位；上架/下架；**一键加黑名单**（自动关闭收录+比价并从导航隐藏）；支持恢复 |
| 提交审核 | 审核站长提交的收录申请，通过自动入站点库；驳回必须填写理由 |

| 广告横幅 | 首页顶部文字广告位：标签、文字、跳转链接、排序、启停 |

| 举报/反馈 | 查看举报与意见反馈，标记已处理 |

## 比价爬虫说明（合规约束）

1. **仅 GET 请求第三方站点公开前台搜索页**，不登录账号、不提交任何表单、不携带 Cookie/凭据。
2. 输入关键词后，遍历所有「开启比价 + 在线」的站点，按发卡系统模板拼接对方搜索 URL，请求 HTML 后用预设选择器提取 **商品标题 / 价格 / 库存**。
3. 三套解析规则在 `src/rules.js`，若目标站改版导致抓取失败，只需修改对应选择器。
4. 保护机制：
   - 同一关键词缓存 **4 分钟**（3~5 分钟区间内）；
   - 并发上限 **3**，单站超时 **8 秒**；
   - 抓取失败自动标记该站点（后台可见红色 fail），**不阻塞整体查询**，前台显示「该站点暂时无法抓取价格」；
   - 全部抓取记录写入日志表，后台可查。
5. 比价结果页顶部固定提示：*价格抓取自第三方公开网页，仅供参考，实际价格以目标网站为准*；只有「前往」跳转按钮，**无任何下单入口**。

## SEO

- `/robots.txt`：允许抓取前台，禁止后台与 API，并声明 Sitemap；
- `/sitemap.xml`：动态生成，包含首页、全部站点页与所有站点详情页。

## 合规硬性约束（已在代码中落实）

- ✅ 无下单、无支付、无卡密发货，全站仅「前往第三方」跳转按钮；
- ✅ 每个站点详情页、比价页、页脚均带免责提示，明确区分本站与第三方；
- ✅ 黑名单机制：违规/跑路站点一键加黑，自动关闭收录展示与比价抓取；
- ✅ 爬虫只读公开前台页面。
